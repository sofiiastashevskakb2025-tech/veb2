Про мене

Студентка спеціальності «Кібербезпека та захист інформації». Цікавлюся прикладним програмуванням, мережевими технологіями та проєктуванням баз даних. Швидко засвоюю нові технології та активно покращую рівень професійної англійської мови.

Освіта

Національний університет «Львівська політехніка»

Спеціальність «Кібербезпека та захист інформації»

Технічні навички

  • Мови програмування: Python, базові знання SQL та HTML/CSS
  • Інструменти розробки: Git, Visual Studio Code
  • Бази даних: Проєктування реляційних баз даних, нормалізація, написання запитів
  • Мережі та безпека: Основи криптографії, моделювання локальних мереж, аналіз вебзапитів
  • Мови: Англійська

Навчальні проєкти

  • Проєкти з програмування (Python): розробка скриптів для обробки даних, створення консольних утиліт з функціями логування та базового захисту інформації.
  • Проєктування баз даних: розробка структури реляційної бази даних для освітнього закладу, оптимізація структури таблиць.
  • Комп'ютерні мережі: побудова та базова конфігурація мережевих топологій у віртуальному середовищі, аналіз мережевого трафіку.
